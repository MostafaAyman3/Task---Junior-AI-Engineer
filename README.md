# AI Data Assistant

**A custom AI Data Assistant built from scratch in Python to manage Excel files natively.**

This project skips bloated frameworks in favor of a fast, transparent, and highly controlled Agentic REPL loop. It allows users to query, analyze, and mutate business datasets (`Real Estate Listings.xlsx` and `Marketing Campaigns.xlsx`) using purely natural language.

---

## Capabilities Showcase

The assistant is capable of handling complex analytical and administrative tasks safely:

**1. Complex Aggregation**
> **User:** "What is the total revenue generated by campaign CMP-8001?"
> **Assistant:** "The total revenue generated by campaign CMP-8001 is $67,314.37." *(The assistant extracts the precise financial figure from the dataset without hallucination).*

**2. Guardrails & Destructive Action Safety**
> **User:** "Change the budget for CMP-8005 to 30000"
> **Assistant:** "I have prepared the update for Campaign CMP-8005. The budget will change to $30,000. Please confirm if you would like me to proceed with this update." *(The assistant pauses, returns a preview, and strictly asks for confirmation before executing).*

**3. Language Mirroring**
> **User:** "كم عدد المنازل المتاحة للبيع في مدينة سياتل؟"
> **Assistant:** "يوجد حالياً 5 منازل متاحة للبيع في مدينة سياتل." *(The assistant detects the user's language and returns a perfectly localized Arabic response natively).*

---

## Features

- **No-Framework Setup:** Zero LangChain or LlamaIndex. Absolute control over the context window, prompt construction, and routing.
- **Bilingual Support (Arabic/English):** Detects the language of the user's prompt and answers natively without cross-contamination.
- **Native Tool-Calling Routing:** Transforms natural language into strict JSON payloads to execute deterministic Python functions.
- **High-Availability Fallback Mechanisms:** Active/Passive API routing. Attempts primary models first and gracefully falls back to secondary models on timeout or rate limit.
- **Destructive Action Guardrails:** Enforces a mandatory `confirm: true` handshake loop for all database updates and deletions.

## Setup Instructions

**Step 1: Clone the repository**
```bash
git clone <repository_url>
cd Task - Junior AI Engineer
```

**Step 2: Install dependencies**
```bash
pip install -r requirements.txt
```

**Step 3: Configure Environment Variables**
Copy the placeholder file and add your actual API keys:
```bash
cp .env.example .env
```
Open `.env` and fill in:
```env
GROQ_API_KEY=your_groq_api_key_here
GEMINI_API_KEY=your_gemini_api_key_here
```

**Step 4: Run the Assistant**
Start the conversational CLI agent:
```bash
python main.py
```
